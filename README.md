#🗣️ Foro-Hub---Challenge---Back-End
Este código simula un foro, el cual por medio de diferentes endpoints permite la creación, listamiento, modificación y eliminación de post ingresado por el usuario, todo esto utilizando el lenguaje de programación JAVA, con el framework spring, ademas para la creación de la API se utilizó el modelo REST y para la autenticación spring security

#🧰 Herramientas utilizadas
🟣 Java
🟣 Framework Spring
🟣 Spring security
🟣 Modelo Api Rest
🟣 Postman
